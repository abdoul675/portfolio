# Portfolio — KONÉ Abdoul Karim

Portfolio personnel : projets, compétences, parcours et contact.

Site : https://abdoul675.github.io/portfolio/

## Fichiers

- `index.html` : contenu des pages.
- `style.css` : présentation et affichage mobile.
- `script.js` : actualisation de l’année.
- `assets/` : portrait et CV.

Les fichiers ont été récupérés depuis la version publiée du portfolio le 10 novembre 2026. Les éléments propres à la protection de l’ancien hébergeur ont été retirés.

## Publication

Chaque modification envoyée sur `main` déclenche le workflow GitHub Actions `Publier le portfolio`, qui publie le site sur GitHub Pages. La publication peut aussi être lancée depuis l’onglet Actions.

## Prévisualisation

Ouvrir `index.html` dans un navigateur, ou servir le dossier avec un serveur de fichiers statiques.
